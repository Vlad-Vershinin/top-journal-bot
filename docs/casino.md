# Fruit Club: закрытая Mini App

Первый режим — слоты: три вертикальных барабана с фруктами, одна выигрышная
линия. Стартовый баланс — 1 000 виртуальных очков, ставки — 10/25/50/100.
Любые два одинаковых символа дают ×2; три одинаковых — множитель из таблицы
в приложении. Множитель включает ставку. Результат генерируется на сервере,
баланс и последние вращения сохраняются в SQLite. Очки нельзя купить,
обменять, перевести или вывести. Когда осталось меньше 10 очков, доступен
бесплатный бонус в 1 000 очков не чаще раза в 24 часа.

`/casino` скрыта из общего меню и отвечает только `ADMIN_TELEGRAM_USER_ID`
в личном чате. API игры проверяет подпись `Telegram.WebApp.initData`, срок
сессии (1 час) и тот же ID. Чужой аккаунт, поддельный ID и открытие в обычном
браузере не дают доступа к балансу или игре. HTML-оболочка не содержит
персональных данных; игровые действия недоступны без авторизации.
Повтор запроса с тем же идентификатором не списывает ставку повторно.

## Запуск на сервере без домена

Из каталога проекта на сервере после получения обновления:

1. Добавьте в серверный `.env`:

   ```dotenv
   COMPOSE_PROFILES=casino
   CASINO_URL=
   CASINO_DB_FILE=data/casino.sqlite3
   ```

   `ADMIN_TELEGRAM_USER_ID` должен содержать ваш числовой Telegram ID.

2. Запустите приложение и туннель:

   ```sh
   docker compose up -d --build
   docker compose logs --tail 100 casino-tunnel
   ```

3. Найдите в логах адрес вида `https://случайное-имя.trycloudflare.com`.
   Вставьте его в `.env`:

   ```dotenv
   CASINO_URL=https://случайное-имя.trycloudflare.com/
   ```

4. Примените адрес к боту:

   ```sh
   docker compose up -d bot
   ```

5. В личном чате отправьте `/casino` и нажмите «Открыть Fruit Club».
   Общую кнопку Mini App в профиле через BotFather включать не нужно.

[Quick Tunnel Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)
предназначен для тестирования: адрес может измениться после перезапуска
контейнера туннеля. В таком случае повторите шаги 3–4. Для постоянного
адреса позже подключите домен и HTTPS-прокси либо постоянный туннель.
Порт приложения опубликован только на `127.0.0.1:8080`; открывать его
внешнему интернету не требуется. Включённый `COMPOSE_PROFILES=casino`
позволяет CI/CD обновлять приложение вместе с ботом.

Проверка состояния:

```sh
docker compose ps
docker compose logs --tail 100 casino
curl http://127.0.0.1:8080/health
```

## Локальная разработка

```sh
python -m journal_bot.casino_server
```

Сервер слушает порт `8080` (можно изменить через `CASINO_PORT`). Обычный
браузер показывает интерфейс с закрытым доступом. Подписанные данные для
настоящей игры выдаёт Telegram при открытии через кнопку `/casino`.
Авторизация основана на [официальной проверке Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app).
