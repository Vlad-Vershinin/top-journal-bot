# Play Room: закрытые мини-игры

При открытии `/play` показывается меню: аватарка и имя из Telegram,
баланс, место в топе и три последние игры. Верхняя навигация содержит
названия четырёх разделов: «Меню», «Режимы», «Лидерборд», «История игр».
В «Режимах» — иллюстрированные карточки с кнопкой «Играть»;
первые три места в топе отмечены золотым, серебряным и бронзовым кубками.
История включает название режима, дату/время по Екатеринбургу и изменение
баланса; старые записи сохранены. История загружается по 20 игр.
Общий баланс принадлежит игроку, а не отдельному режиму.

Первый режим — «Фруктовый микс»: три вертикальных барабана с фруктами, одна
линия комбинаций. Стартовый баланс — 1 000 монет, цена хода — 10/25/50/100.
Любые два одинаковых символа дают ×2; три одинаковых — множитель из таблицы
в приложении. Множитель включает ставку. Результат генерируется на сервере,
баланс и игры сохраняются в SQLite. Когда осталось меньше 10 монет, доступен
бонус в 1 000 монет не чаще раза в 24 часа.

`/play` скрыта из общего меню и отвечает владельцу `ADMIN_TELEGRAM_USER_ID`
и тестировщикам из `PLAY_TESTER_IDS` в личном чате. API игры проверяет подпись
`Telegram.WebApp.initData`, срок сессии (1 час) и список доступа. Чужой аккаунт, поддельный ID и открытие в обычном
браузере не дают доступа к балансу или игре. HTML-оболочка не содержит
персональных данных; игровые действия недоступны без авторизации.
Повтор запроса с тем же идентификатором не списывает ставку повторно.

### Пригласить тестировщиков

Попросите друзей отправить боту `/id`. В `.env` на сервере добавьте их числовые
Telegram ID через запятую (не username):

```dotenv
PLAY_TESTER_IDS=123456789,987654321
```

Затем примените настройки к обоим сервисам:

```bash
docker compose --profile casino up -d --force-recreate bot casino
```

Владелец разрешён автоматически, добавлять его в список не нужно. Друзья
открывают `/play` в личном чате. У каждого свой баланс и история, топ общий.
Админ-команды им не выдаются. Для отзыва доступа удалите ID из списка и
повторите перезапуск: даже уже открытая Mini App перестанет принимать запросы.
Пустой список оставляет доступ только владельцу. `.env` не коммитится.

## Запуск на сервере без домена

Из каталога проекта на сервере после получения обновления:

1. Добавьте в серверный `.env`:

   ```dotenv
   COMPOSE_PROFILES=casino
   PLAY_URL=
   CASINO_DB_FILE=data/casino.sqlite3
   ```

   `ADMIN_TELEGRAM_USER_ID` должен содержать ваш числовой Telegram ID.

2. Запустите приложение и туннель:

   ```sh
   docker compose up -d --build
   docker compose logs --tail 100 casino-tunnel
   ```

3. Найдите в логах адрес вида `https://случайное-имя.trycloudflare.com`.
   Вставьте его в `.env`:

   ```dotenv
   PLAY_URL=https://случайное-имя.trycloudflare.com/
   ```

4. Примените адрес к боту:

   ```sh
   docker compose up -d bot
   ```

5. В личном чате отправьте `/play` и нажмите «Открыть мини-игры».
   Общую кнопку Mini App в профиле через BotFather включать не нужно.

[Quick Tunnel Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)
предназначен для тестирования: адрес может измениться после перезапуска
контейнера туннеля. В таком случае повторите шаги 3–4. Для постоянного
адреса позже подключите домен и HTTPS-прокси либо постоянный туннель.
Порт приложения опубликован только на `127.0.0.1:8080`; открывать его
внешнему интернету не требуется. Включённый `COMPOSE_PROFILES=casino`
позволяет CI/CD обновлять приложение вместе с ботом. Внутренние имена
Docker-сервисов, файла базы и Python-модулей оставлены прежними для совместимости.
Старый `CASINO_URL` поддерживается, если `PLAY_URL` не заполнен.

Проверка состояния:

```sh
docker compose ps
docker compose logs --tail 100 casino
curl http://127.0.0.1:8080/health
```

## Локальная разработка

```sh
python -m journal_bot.casino_server
```

Сервер слушает порт `8080` (можно изменить через `CASINO_PORT`). Обычный
браузер показывает интерфейс с закрытым доступом. Подписанные данные для
игры выдаёт Telegram при открытии через кнопку `/play`.
Авторизация основана на [официальной проверке Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app).
